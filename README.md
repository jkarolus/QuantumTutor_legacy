

Clone repository to local system.

# Add Chrome Extension.

1. Go to the Extensions page chrome://extensions
2. Enable Developer Mode by clicking the toggle switch next to Developer mode.
3. Click the Load unpacked button and select the cloned directory.

For any issues faced to install extension or detailed explanation, check https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world .
